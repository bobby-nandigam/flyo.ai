## What this validates (spec §11, §14)

1. **No negative refunds** — across 50k randomised cases, every expected refund is
   ≥ 0; the engine floors and flags impossible inputs rather than emitting a
   negative figure.
2. **Reproducibility** — identical inputs yield byte-identical audit output, so any
   figure the platform shows can be re-derived.
3. **Throughput headroom** — the pure engines process far beyond interactive load,
   so the bottleneck in production is I/O (DB), not computation.

## Correctness guarantees beyond throughput

The full test suite (103 tests) encodes the seven financial invariants, tenant
isolation, the refund state machine, deterministic reconciliation matching,
document extraction, policy computation, and the evidence-grounded investigation
engine. The benchmark complements the suite with scale and timing evidence.
